Project

Good Morning Dashboard

  • Python
  • FastAPI
  • APScheduler
  • Docker
  • pytest

A FastAPI service that says when to leave for the train. It plans SEPTA Regional Rail trips with transfers, tracks live delays, and sends a weekday push with the train home and the next ones that still connect. It keeps following both legs until the connecting train leaves, pushing again only if things get worse.

Project

WeatherTunes

  • JavaScript
  • Tone.js
  • Web Audio
  • Open-Meteo

Turns today's forecast into a short piece of music. Each hour gets two beats: temperature shapes the melody, cloud and rain pick the scale, air pressure picks the key, wind sets the tempo, and the climate picks the instruments. The sky plays too, from moonrise bells to meteor showers. Music-theory rules keep it in tune, and the same place and day always gives the same song, with liner notes explaining why.
